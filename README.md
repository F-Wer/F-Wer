# Hi, I'm Fabian 👋

SAP ABAP developer & HCM consultant from Germany. I build open-source tooling for SAP
developers and spend a lot of time making AI assistants useful inside real ABAP systems.

[![LinkedIn](https://img.shields.io/badge/LinkedIn-Fabian%20Werner-0A66C2?logo=linkedin&logoColor=white)](https://de.linkedin.com/in/fabian-werner-9236021aa)

## 🧰 What I work on

- **SAP ABAP** — classic ABAP, RAP, CDS, OData/SEGW, Smart Forms & SAPscript, transports, abapGit
- **SAP HCM** — consulting and development around HR processes
- **AI-assisted development** — MCP servers and agent workflows that read, write and test ABAP over ADT
- **Side projects** — Android apps in Kotlin, web apps in TypeScript/Next.js, small games, automation scripts
